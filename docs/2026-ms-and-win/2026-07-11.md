**ここ一週間（2026年7月4日〜11日頃）のMicrosoftおよびWindows 11関連の主な動き**を、X（Twitter）とウェブ上の最新情報からまとめます。古い情報は除外し、Insiderビルド、セキュリティ/更新関連、企業ニュースを中心に整理。

### 1. Windows 11 Insider Previewの新ビルド（Experimentalチャネル中心）
Microsoftは7月6日頃に新ビルドをリリース。**Cloud Rebuild**という新しい回復オプションが注目されています。これはPCがブートできない場合でもクラウドからクリーンなOS状態を復元する機能で、信頼性向上を目指したものです。また、タスクバーの柔軟性向上（移動・サイズ変更など）、File Explorerの高速化、設定/UIの刷新、アカウント管理の改善などが含まれています。

- [@nextgenos2026](https://x.com/nextgenos2026/status/2075593593008570548) がBuild 26300.8772の詳細（Cloud Rebuild、バックアップ/復元、デフォルト設定など）を共有。
- [@NeowinFeed](https://x.com/NeowinFeed/status/2074255082560836007) がExperimentalビルドのリリースを報じ、回復オプションやタスクバー改善を強調。
- [@AlternativeTo](https://x.com/AlternativeTo/status/2074849489731629558) も同様の新機能（Cloud Rebuild、UI現代化）を紹介。

これらはユーザーからのフィードバック対応（パフォーマンス、利便性）の一環で、7月14日のセキュリティ更新にも関連する改善が期待されます。

### 2. セキュリティ更新と脆弱性対応
- Microsoft Exchange Onlineの脆弱性（CVE-2026-54998）に関する解説が登場。影響範囲と対策が議論されています。
- [@Teeeda_worker](https://x.com/Teeeda_worker/status/2075837595452592148) が詳細解説記事を共有。
- Secure Boot関連の更新で一部Windows 11 PCに互換性問題が発生（古い証明書関連）。Microsoftは一時ブロックし、メーカー対応を進めています。影響デバイスは自動解決予定で、即時リスクはないとされています。
- OWA Lightクライアントの廃止予定も発表。

### 3. Microsoft全体の企業ニュース（Xbox中心のリストラ）
Microsoftは約4,800人の人員削減（全従業員の約2.1%）を発表。Xbox部門が大きく影響を受け、約3,200人の削減（即時1,600人＋今後）と複数スタジオのスピンオフ/閉鎖が計画されています。AI投資シフトや事業再編の一環で、id Softwareなども一部影響。

- [@grok](https://x.com/grok/status/2075837548664905748) がid Softwareの声明を引用（残存チームで開発継続）。

### 4. その他の動き
- Windows 10のサポート延長（2027年まで）がWin11採用率に影響しているとの指摘。
- 全体として、MicrosoftはWin11の安定性・ユーザー体験向上（AI以外も）を2026年に注力。7月更新ではPoint-in-time Restoreや更新一時停止機能の強化なども予定。
