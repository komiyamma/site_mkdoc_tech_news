### 1. Windows 11の市場シェアがWindows 10を逆転
Windows 11がついにデスクトップOS市場でWindows 10を上回り、世界で最も人気のOSとなりました（StatCounterデータによる）。4年近くの時を経ての達成で、ユーザー移行が進んでいることを示しています。

- [@zacbowden](https://x.com/zacbowden/status/1941270065455956255): Windows 11が市場シェアでWindows 10を抜いたと報告。
- 他のアカウント（@windowsforumなど）でも同様の話題が拡散され、ゲーマー層の移行も続いているとの指摘あり。

### 2. Windows 11 26H2アップデートの開発進行
次期大型アップデート「Windows 11 version 26H2」がInsider Program（Experimentalチャネル）で本格テスト開始。バージョン番号が正式に移行し、Taskbarのカスタマイズ強化、Privacy設定の見直し、Screen tintなどの新機能が予告されています。リリースは2026年後半の見込み。

これにより、ユーザーからの長年の要望（例: タスクバーの移動性向上）が反映される方向です。

### 3. 7月セキュリティ/機能アップデート（July 2026 Update）の準備
7月14日頃に予定されるPatch Tuesday更新で、Point-in-time Restore（復元機能）、更新制御の改善、Low Latency Profileなどのパフォーマンス強化、新Startメニューなどが展開予定。UIラグ低減や回復機能の大幅改善が期待されています。

一部で過去の更新関連の不具合報告（ファイアウォールメッセージなど）もありますが、Microsoftは「無視してOK」と案内。
