**過去1週間（2026年6月28日〜7月5日頃）の主な新情報まとめ**（古い発表や比較記事は除外）。主に公式リリース、イベント、X上の開発者投稿から収集し、日本語で整理。

### **Vercel（v0含む）**
Vercel Ship 26イベント（NYCなど）が6月30日頃に開催され、**Vercel Services**が7月1日にローンチ。フロントエンドとバックエンドを1プロジェクトで統合可能になり、バックエンド変更時もフルプレビューURLが生成され、サービス間はプライベートネットワークで通信。Microservicesが第一級市民に。

- **@ctatedev**（Vercel Labs）がShipの主要発表を詳細にまとめ：Vercel Services、eve（エージェントフレームワーク）、WebSocketサポート、Vercel Agent（ダッシュボード内自律調査）、Container Registry、AI SDK 7など多岐にわたるアップデートを報告。
- **@theayush**：Vercel Servicesにより、1プロジェクトでフロント+バックエンドをアトミックにデプロイ可能になった点を強調（ベータからGA）。

v0関連の具体的な新機能言及は限定的だったが、Ship全体でエージェント/ AI統合が強化。

### **Cloudflare**
**7月1日**に「Your site, your rules: new AI traffic options」を発表。AIクローラーを**Search / Agent / Training**の3分類で管理可能に（全顧客対象、Freeプラン含む）。広告ページではTraining/Agentをデフォルトブロックする新デフォルトを9月15日から適用。Agentic Internet向けの分類・分析強化とパートナーシップも。

ボット/エージェントトラフィックが人間を上回る状況（57%超）への対応として注目。

### **Supabase**
**6月上旬のDeveloper Update - June 2026**が引き続き話題（Series F $500M調達 @ $10B valuation、GIC主導）。Multigres 0.1 alphaリリースなどオープンソース/Postgres強化。過去1週間の新規投稿は少ないが、資金調達の余波で議論継続。

Xでは日常ツールとして言及される程度（新機能具体例は前月中心）。

### **Firebase / GCP**
**Firebase CLI v15.22.3**（6月25日頃）が最近のリリースノートに登場。新機能・Authentication変更含む。

Cloud Next '26での大規模発表（Firebase SQL Connectへの進化、Firestoreエンジン強化、Dart for Cloud Functionsなど）は4月頃のため除外。GCP全体ではCloud Run Worker Pools GAなどAI/サーバーレス関連の継続アップデートあり。

XではFirestore利用事例（GenUIキャッシュなど）が散見されたが、大規模新発表はなし。

### **Azure**
**7月3日頃のAzure Update**（John Savill動画）で：
- Foundry Toolboxes GA
- Claudeモデル（Sonnet 5など）がAzure Databricks / Microsoft FoundryでGA（NVIDIA GB300加速）
- VM即時リストア、Blob整合性、PostgreSQL PowerShellモジュールなど。

Claude統合が特に注目され、Azureネイティブでのエージェント構築が強化。
