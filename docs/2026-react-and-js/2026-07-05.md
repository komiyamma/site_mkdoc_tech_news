### TypeScriptの大きな進展：TypeScript 7.0 RCリリース
Microsoftが6月18日頃に**TypeScript 7.0 RC**を公開。Go言語で完全に書き直されたネイティブコンパイラが導入され、**TypeScript 6.0比で約10倍高速**な型チェックを実現（大規模コードベースで顕著）。並列処理も強化され、日常開発のビルド時間が大幅短縮の見込みです。安定版は数週間以内の予定で、Next.jsなどとの統合議論も活発化しています。

X上でも「TypeScript 7.0 RC: The Go Rewrite Migration Guide」などの言及が見られ、アップグレードの注目度が高いです。

### React/Next.jsエコシステムの更新
- **Next.js 16.3**関連のプレビュー/アップデートが進行中。Turbopackの改善（Rust版React Compiler実験的サポート）、AI機能強化、**Instant Navigations**（SPA並みのレスポンシブネス向上）などがハイライトされています。
- **React Compiler**の採用が進んでおり、手動memoization（useMemo/useCallback）の必要性を大幅に減らす方向性。Next.js設定で有効化可能。

**This Week In React 288**（@sebastienlorber）では、Next.js、React Compiler、use()、TanStack Start、Storybookなどのトピックがまとめられています。

### ライブラリ/ツールの新リリース・プロジェクト
- **React Hook Form v7.81.0**リリース（@HookForm）。新`<FieldArray />`コンポーネント追加、パフォーマンス向上、useFieldArray/resetなどの修正多数。フォーム実装の定番ツールとして引き続き進化中です。
- TypeScript + ReactプロジェクトのテンプレートやAI統合ツール（例: AI-powered code conversion、Next.js + Supabase + Stripeでのソロ開発事例）がX上で共有されています。
