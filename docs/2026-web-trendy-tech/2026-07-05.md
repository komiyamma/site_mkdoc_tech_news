### shadcn/ui：Base UIがデフォルトに変更（7月最大の話題）
shadcn/uiの最新アップデートで、**Base UI（Radixの後継）が新プロジェクトのデフォルト**になりました。Radixも引き続きサポートされ、移行は任意（スキルを使った段階的移行ツールも提供）。チャットインターフェース向け新コンポーネント（MessageScroller、Bubbleなど）も追加され、AIチャット構築がしやすくなっています。

- [@hackernewstop5](https://x.com/hackernewstop5/status/2073641647943057904) やコミュニティで即座に話題に。「Shadcn/UI now defaults to Base UI instead of Radix」と共有。

この変更は、Base UIの安定性（1.6.0、ダウンロード数急増）とコミュニティの選択（新プロジェクトで2:1でBase UI優勢）を反映したものです。新規プロジェクトは `npx shadcn init` で自動的にBase UIを選択。

### Tailwind CSS：Insidersプログラム開始
**Tailwind CSSのスポンサーシッププログラム「Tailwind Insiders」**がローンチ。私的Discord、Cursor/Claude用ルール、VS Codeテーマ、早期ドキュメントなどが特典。Tailwind 4.1.0での算術値バグ修正（calc内のパーセント）も言及されました。

- [@adamwathan](https://x.com/adamwathan/status/1941162664652411106) が直接発表し、大きな反響。

多くの開発者がReact + TailwindのUI構築（Targetクローンなど）で活用中。

### Biome：Vue/Svelte/Astro/Angularサポート進行中
**BiomeがVue.js、Svelte、Astro、Angularのフルサポート**に向けた作業を開始。Issueでコミュニティ議論が活発。

- [@biomejs](https://x.com/biomejs/status/1940130986412355895) の公式投稿で注目を集めました。

Webプロジェクトのフォーマッター/リンターとして人気継続中。

Next.jsはMicroSaaSブートストラップCLIや各種アプリ構築で頻出。**Next.js 15.4/15.5**（Turbopack改善、安定性向上）や16 beta予告が背景にあり、Vercel + Prisma + shadcn/uiとの組み合わせが定番。

### React Aria Components：アクセシビリティ議論
